# 2026-02-26 — code review: feat live web (part 2)

## Что исправлено/добавлено

### Безопасность и корректность
- `ws_live`: авто-выбор активного прогона теперь валидирует `run_name` перед чтением файла событий.
- Граф: governance-агенты (`aud_*`, `juror_*`) помечаются как `has_reputation=false`, чтобы UI не рисовал репутацию там, где её быть не должно.

### UX / библиотека
- Правый “collapse” больше не перекрывает заголовок “Активность”.
- Разделы **Типы** и **Личности** больше не пустые: добавлены стартовые элементы в `data/agent_types/` и `data/personalities/`.

### Запуски (LLM-only)
- В вебе запуск всегда идёт через `runner=cognitive` (mock-режим не используется).
- Backend откажет в запуске, если не задан `OPENAI_API_KEY`.

### Редактируемость шаблонов
- Списки шаблонов сценариев и режимов governance в UI теперь загружаются из API:
  - `GET /api/templates/scenarios`
  - `GET /api/templates/governance`

### Вторичные агенты
- Добавлен admin endpoint генерации вторичных агентов через LLM:
  - `POST /api/ai/secondary-agents`
- В редакторе сценария можно задать:
  - сколько `fam_*` и `soc_*` агентов добавить,
  - промпт “среды/контекста”,
  - режим “заменить существующих fam_/soc_”,
  и получить обновлённый `ScenarioConfig` в `sim_config` (дальше можно вручную править JSON).

## Как запустить

1) Убедитесь, что в `.env` задан `OPENAI_API_KEY` (и при необходимости `OPENAI_BASE_URL`, `LLM_MODEL`).
2) Запуск:
   - `MAGISTRY_DEV=1 ./web/start.sh --port 8765`
3) Открыть:
   - `http://localhost:8765`
